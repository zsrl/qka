# 避坑指南与最佳实践

量化策略研发是一项严谨的科学工程。回测中哪怕一个极细微的漏洞，都可能让纸面上年化 200% 的“圣杯策略”在实盘中迅速归零。

本章节总结了使用 QKA 以及进行 A 股量化研究时最重要的实践规范与避坑原则。

---

## 1. 规避未来函数 (Look-ahead Bias)

未来函数是指在策略决策时，“不小心”使用了在当前交易日尚未发生的未来信息。

### 常见的未来函数陷阱
- **使用了当天的收盘价做日内买入**：在实盘中，你在下午 14:50 之前不可能确切知道 15:00 的最终收盘价。
- **使用了包含未来信息的时序滤波指标**：例如双向 HP 滤波、某些分形几何指标或未限制右边界的多项式拟合。
- **因子跨期对齐错误**：例如在 2024 年 3 月 1 日使用了 2023 年年报数据，但实际上该上市公司直至 2024 年 4 月 25 日才正式披露财报。

### QKA 的防范保障
1. **严格的时空隔离**：在 `on_bar(date)` 中，`self.get()` 严格只提供截止当天的数据，`self.history(factor, window)` 绝不允许索引超出 `date`。
2. **分析工具隔离**：包含未来函数的算法（如 `Analysis.zigzag`）被严格归置在事后分析模块中，严禁放入策略 `Strategy` 内部。

---

## 2. 前复权（qfq）负价格防范

在 A 股市场长期高额现金分红或大规模除权除息的标的（如银行、大型国企），若采用**前复权（qfq）**回测，其 10 年或 15 年前的早期历史复权价格可能会出现**负数**或接近零的极小值。

### 潜在风险
若在策略中直接用负价格执行买入：
$$\text{Cost} = \text{Shares} \times (-2.50) = -2500 \text{ 元}$$
这将导致“买入股票账户资金反而增加”的荒谬现象。

### 最佳实践
- **QKA 原生拦截**：`Broker.buy()` 底层内置强制校验，若检测到 `price <= 0` 会直接拒单并打印 Warning 日志。
- **策略端主动防御**：在 `on_bar` 遍历标的时，建议始终加上非正价格过滤：
  ```python
  price = float(close[sym])
  if price <= 0:
      continue  # 忽略负值除权异常价格
  ```

---

## 3. 始终使用 `self.sizing`，避免手动算股数

初学者常习惯在策略中手写：
```python
# ❌ 不推荐的做法：容易产生碎股，且未预留手续费导致资金不足拒单
size = int(self.broker.cash * 0.2 / price)
self.broker.buy(sym, price, size)
```

这样写存在两大隐患：
1. `size` 可能是 `137` 股，不满足 A 股一手 100 股的整手规则。
2. 即使算出了 `100` 股，若账户总资金刚好够买 100 股，由于没有预留万 2.5（最低 5 元）的佣金和滑点，会导致 `Broker` 判定现金不足而拒单。

### 最佳实践
```python
# ✅ 推荐做法：自动按 100 股取整，并预留佣金和滑点空间
size = self.sizing.percent(0.2, price)
if size > 0:
    self.broker.buy(sym, price, size)
```

---

## 4. 善用 `warmup`，摒弃策略内的跳过逻辑

在许多老旧框架中，由于没有预热机制，如果策略使用了 60 日均线，前 60 天数据全为 `NaN`，用户被迫在策略内部写：
```python
# ❌ 丑陋且容易遗漏的写法
if len(hist) < 60:
    continue
```

### 最佳实践
在定义 `Data` 时直接声明 `warmup=60`：
```python
data = Data(
    symbols=['000001.SZ'],
    factors={'sma_60': ('ta.trend.sma_indicator', 'close', 60)},
    warmup=60,  # 提前多读 60 天计算指标
)
```
框架计算完毕后会自动截断多读的历史，策略在回测第一天就能直接拿到有效的 `sma_60`，代码极其干净。

---

## 5. 充分利用 `Simulate` 验证边界逻辑

在策略正式跑全市场回测之前，强烈建议先用 `Simulate` 标的构建测试集：
- 用持续上涨标的验证：策略是否真的能拿住利润、适时止盈？
- 用持续下跌标的验证：策略的止损逻辑是否被坚决触发？
- 用高频震荡标的验证：网格或高抛低吸策略在无趋势震荡行情下的资金利用率与摩擦成本。
