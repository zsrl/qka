# 现代 Web 可视化控制台

为了让量化策略的开发、测试、数据探索与绩效诊断更加直观高效，QKA 在 `console/` 目录下内置了现代化的轻量级 Web 控制台。

告别繁琐的纯黑盒命令行，通过简洁美观的响应式界面即可完成全流程量化操作。

---

## ⚡ 一键启动

在项目根目录下运行一键启动脚本即可（自动在默认浏览器中打开 `http://127.0.0.1:15002`）：

::: code-group

```bash [macOS / Linux]
# 1. 执行启动脚本
./start.sh

# 2. 或指定自定义端口启动
./start.sh --port 15003
```

```cmd [Windows]
REM 双击 start.bat 或在命令行运行：
start.bat
```

```bash [QKA CLI 命令行]
# 已安装 qka 包时：
qka console --port 15002
```

```bash [Python 模块直接启动]
python console/server.py --port 15002
```

:::

## 核心功能面板

### 1. 📊 总览大屏 (Overview)
- **运行环境状态**：QKA 核心版本、Python 解释器版本、原生引擎状态探测。
- **存储与缓存监控**：展示当前本地 `.qka/` 或 `datadir/` 中的已缓存文件数与磁盘占用体积。
- **快速向导**：提供策略开发、数据检索、模拟合成的快速指引。

---

### 2. 🎯 股票池管理 (Stock Pool)
- **核心理念：选赛道、做减法、精选股**：
  - 自上而下选对行业事半功倍：坚决清除长期下行行业，聚焦**科技、消费、周期、大金融**四大高景气赛道。
  - **科技核心细分子赛道**：光通信（800G/1.6T/CPO）、存储（HBM/DRAM）、国产算力（AI服务器/GPU/调度）、电力（AI基建/燃气轮机/发电机/电网/储能）、新材料、半导体设备。
  - **消费做减法**：必选消费只选创新药，可选消费只选新消费。
  - **周期做减法**：只选能源金属（锂/钴/镍）与战略金属（铜/钼/钨/稀土），以及锂电与储能周期复苏。
- **三级漏斗包含关系架构（交易 ⊆ 精选 ⊆ 基础）**：
  1. **📚 基础股票池 (全量底池)**：全量覆盖所有标的，包含所有的精选股与交易股。通过券商深度研报、每日微博功课笔记（如“专业证券和财富秘钥”）动态录入。
  2. **⭐ 精选股票池 (包含交易股)**：精选好行业好公司，**包含所有的交易股**，且所有标的必定同时属于基础股票池。
  3. **⚡ 交易股票池 (实盘盯盘)**：极少数看盘盯盘纳入实盘交易范围，看长做短，**必定同时属于精选池与基础池**。
- **关联查询与关联打标**：标的自动级联打标（`[⚡交易] [⭐精选] [📚基础]`），支持一键筛选精选池（自动拉出全部精选+交易标的）或基础池（全量标的）。
- **智能研报与文本萃取**：支持直接粘贴券商研报文本或微博短文，自动提取股票代码、中文名称与驱动逻辑并批量入池。
- **动态盯盘与风控警示**：
  - **分步止盈提醒**：单日涨幅偏离度大个股和连续 3 日积累一定涨幅个股分步止盈，落袋为安。
  - **分步低吸契机**：核心赛道好公司回调，大跌分步低吸。
- **量化回测一键直通**：点击「⚡ 载入交易池至回测」，一键将当前交易股票池标的同步至策略回测引擎。
- **SQLite 原生持久化**：底层采用标准 SQLite 数据库（`stock_pools.db`，支持 WAL 高并发模式），标的增删改查、层级升降级与研报导入秒级事务落盘，零外部依赖。

### 3. 🧪 策略开发与回测工坊 (Strategy Studio)
- **预置经典量化策略**：
  1. *双均线动量择时策略*
  2. *布林带突破 + ATR 风险平价策略*
  3. *多标的横截面动量轮动策略*
  4. *RSI 超买超卖均值回归策略*
- **内置代码编辑器**：支持在线查看、修改与调试继承自 `qka.Strategy` 的策略源码。
- **回测参数一键调控**：本金（默认 20 万）、标的列表、起始/截止日期、基准指数（`000300.SH`）、预热天数（`warmup`）。
- **13 项核心绩效体检大屏**：
  - 总收益率、年化收益率、夏普比率、最大回撤、卡玛比率、胜率、盈亏比、总交易笔数等 KPI 实时卡片。
  - **累计净值走势 vs 基准指数对比折线图**。
  - **动态水下回撤百分比曲线**。
  - **逐笔成交流水明细表**（含委托价、滑点后实际撮合价、佣金支出）。

---

### 3. 📈 行情与指标探索 (Data Explorer)
- **全市场标的覆盖**：输入任意 A 股股票代码、ETF 基金代码或可转债代码（如 `000001.SZ`、`510300.SH`、`159915.SZ`）。
- **多源切换**：支持 `tickflow`（免密默认）、`baostock`（含估值指标）、`tdx`（通达信本地源）。
- **复权机制切换**：前复权（`qfq`）、后复权（`hfq`）、不复权（`bfq`）。
- **专业 ECharts K 线大屏**：
  - 缩放平移交互（DataZoom）、十字准星光标。
  - 日 K 线 + 成交量柱状图 + 5日/20日均线平滑叠加。
  - 最近历史数据切片表格展示。

### 4. 🎲 模拟标的现场合成 (Simulate Playground)
- **数学方程现场推演**：
  $$r_t = \text{drift} + \text{reversion} \times (\log P_{\text{anchor}} - \log P_{t-1}) + \text{vol} \times \epsilon_t$$
- **可视化参数调优**：
  - 日漂移率 $\mu$（趋势方向）
  - 均值回复强度 $\theta$（围绕中枢震荡程度）
  - 日波动率 $\sigma$（价格波动剧烈度）
- 一键合成并在无真实网络依赖的环境下验证策略防假突破与止损逻辑。
