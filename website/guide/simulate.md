# 模拟标的 (Simulate)

在量化策略研发过程中，直接使用真实历史数据常遇到两大痛点：
1. **策略逻辑难以隔离验证**：策略在真实数据上亏损，究竟是因为市场环境不配合，还是策略本身的买卖判断、仓位计算代码写错了？
2. **极端场景样本匮乏**：例如想要测试策略在持续单边暴跌、极端宽幅震荡或单边大牛市中的熔断与仓位管理能力，往往难以快速找到完全契合的历史区间。

针对这一问题，QKA 独创了 **`Simulate` 现场行情合成引擎**。

---

## 快速使用

`Simulate` 对象可以直接放入 `Data(symbols=[...])` 中，与真实股票代码混排使用，接口与真实标的完全同构：

```python
from qka import Data, Simulate

# 构造包含真实股票与模拟标的的混合数据源
data = Data(
    symbols=[
        '600000.SH',  # 真实股票代码
        Simulate('SIM.BULL', drift=0.002, reversion=0.0, vol=0.01),      # 强单边上涨牛市
        Simulate('SIM.BEAR', drift=-0.002, reversion=0.0, vol=0.015),    # 持续单边下跌熊市
        Simulate('SIM.OSC',  drift=0.0, reversion=0.08, vol=0.02),       # 均值回归大幅震荡
    ],
    factors={
        'sma_20': ('ta.trend.sma_indicator', 'close', 20),
    }
)

df = data.get(start_date='2023-01-01', end_date='2024-01-01')
```

## 数学演化原理

`Simulate` 基于对数价格空间中的**奥恩斯坦-乌伦贝克过程（Ornstein–Uhlenbeck / 带漂移的均值回复过程）**离散化生成：

$$r_t = \mu + \theta \cdot (\log P_{\text{anchor}} - \log P_{t-1}) + \sigma \cdot \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, 1)$$

三个参数各司其职：

| 参数 | 数学符号 | 默认值 | 作用与解释 |
|------|----------|--------|------------|
| `drift` | $\mu$ | `0.0` | **日漂移率**。正数代表整体上涨趋势（如 `0.001`），负数代表整体下跌走势（如 `-0.001`），`0` 表示无趋势方向 |
| `reversion` | $\theta$ | `0.0` | **均值回复强度**。必须 $\ge 0$。数值越大，价格越紧密地围绕中枢震荡（半衰期 $T_{1/2} = \frac{\ln 2}{\theta}$）；为 `0` 时不回复 |
| `vol` | $\sigma$ | `0.012` | **日波动率**。必须 $> 0$。例如 `0.015` 代表单日波动标准差约为 1.5% |

::: tip 纯随机游走
当 `drift = 0` 且 `reversion = 0` 时，模型退化为纯几何布朗运动（纯随机游走），非常适合用来检验策略是否能有效识别无趋势伪信号。
:::

## 典型应用场景

### 1. 检验趋势策略的跟涨与止损
```python
# 构造一只持续单边上涨的标的
sim_bull = Simulate('TEST.BULL', drift=0.003, reversion=0.0, vol=0.01)

# 如果是一个动量/突破策略，回测此标的若没有重仓吃满涨幅，说明入场阈值过严或仓位算法有误
```

### 2. 检验均值回归与网格策略
```python
# 构造高频中枢震荡标的
sim_osc = Simulate('TEST.GRID', drift=0.0, reversion=0.10, vol=0.025)

# 均值回复半衰期短，检验网格策略的高抛低吸触发频率与现金管理
```

### 3. 单元测试与持续集成 (CI)
在项目的自动化测试脚本中，使用 `Simulate` 代替真实数据：
- **零网络依赖**：无需请求外部网络，不会因数据源 API 限流或网络波动导致 CI 报错。
- **计算瞬时完成**：纯 NumPy 向量化矩阵生成，回测秒级完成。
