# 🤖 AI Agent 技能集成

在大语言模型（LLM）驱动编程的时代，QKA 率先支持了 **AI Agent 标准化技能协议（Agent Skills Protocol）**。

通过将框架的完整 API 签名、最佳实践与严苛约束封装为标准化技能，你可以让 **Claude Code**、**Cursor**、**Windsurf** 等现代 AI 编程智能体在你的项目中直接化身为资深 A 股量化专家。

---

## 一键安装技能

在你的量化项目根目录下执行以下命令：

::: code-group

```bash [通用 Skills 安装（推荐）]
npx skills add zsrl/qka
```

```bash [克隆或手动配置]
# 如果需要本地定制，可直接将 QKA 仓库中的 skills 目录复制到工作区：
cp -r /path/to/qka/skills/qka .skills/qka
```

:::

安装完成后，你的 AI 编程助手将自动检测并激活该技能，并在每次你需要生成策略时无感知加载。

---

## AI 技能为智能体注入了什么？

大语言模型（如 Claude 3.7 / GPT-4o / Gemini 2.5）在编写量化策略时常出现“幻觉”：编造不存在的 API、沿用其他回测框架的旧习惯、忘记整手 100 股限制、在策略循环内重复低效计算指标等。

QKA 技能向智能体注入了确定性规则库：

| 智能体常见幻觉 | QKA 技能强制规范 |
|----------------|------------------|
| 习惯写 `def on_bar(self, date, get):` | 强制纠正为 `def on_bar(self, date):` |
| 习惯写 `self.params.get('period')` | 强制纠正为直接使用实例属性 `self.period` |
| 在循环内手写 `if len(hist) < 20: continue` | 强制要求在 `Data` 中配置 `warmup=20` |
| 手动除法计算股数造成碎股或穿仓 | 强制要求使用 `self.sizing.percent` 等安全接口 |
| 忘记前复权除权异常导致负价格买入 | 强制要求在遍历标的时增加 `if price <= 0: continue` 校验 |

## 实战 Prompt 提示词精选

安装技能后，你可以直接向 AI 助手提出高层次的策略需求：

### 示例 1：布林带突破与 ATR 风险平价策略
> **Prompt**：
> “请使用 QKA 框架编写一个针对中证 500 ETF（510500.SH）的布林带突破策略。要求：
> 1. 在 `Data` 中预计算 20 日布林带与 14 日 ATR，并设置 `warmup=20`。
> 2. 当收盘价突破上轨时触发买入信号，使用 `self.sizing.atr_risk` 进行风险平价仓位管理，单笔风险限制为 1.5%。
> 3. 当收盘价跌破中轨时全部卖出平仓。
> 4. 回测区间 2022-01-01 至 2024-12-31，以中证 500 为基准，并生成 HTML 交互式报告。”

### 示例 2：全市场多因子横截面动量轮动
> **Prompt**：
> “使用 QKA 编写一个多标的动量轮动策略。候选标的为平安银行（000001.SZ）、招商银行（600036.SH）、贵州茅台（600519.SH）。
> 1. 因子预计算 20 日日均收益率动量和 5 日短期均线。
> 2. 每日 `on_bar` 中获取最新横截面，计算过去 20 天累计收益最高的那只股票。
> 3. 若当前持仓不在第一名，则平仓换股，将 95% 资金换仓至第一名标的。
> 4. 运行回测并打印夏普比率、年化收益和最大回撤。”

### 示例 3：用 Simulate 进行极端暴跌场景压力测试
> **Prompt**：
> “帮我构造一个使用 `qka.Simulate` 的单元测试脚本。生成一只日漂移 -0.003、日波动 2.5% 的极端单边暴跌模拟标的，验证我编写的移动止损策略在遇到黑天鹅时能否在 8% 损失内强制平仓。”
