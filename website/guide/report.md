# 交互式 HTML 报告

回测结束后，只看终端输出的几行数字往往难以全面掌握策略的收益波动特征与极端行情表现。

QKA 内置了基于 **Plotly** 引擎的专业交互式回测报告生成器，只需一行代码即可生成单文件自包含（Self-contained）的现代化 HTML 诊断大屏。

---

## 一键生成报告

在 `bt.run()` 完成后，调用 `bt.report()`：

```python
# 自动生成并在 reports/ 目录下保存
report_file = bt.report(
    title="双均线动量择时策略",
    output_path="my_report.html"
)
print(f"报告已生成至: {report_file}")
```

生成的 HTML 报告内嵌了所有必要的 CSS、JS 与离线图表数据，**无需启动任何后端服务**，双击即可在任何现代浏览器中打开，也可直接发送给团队成员或投研客户进行汇报。

---

## 报告核心看板模块

### 1. 核心绩效指标看板 (Metric Cards)
置顶展示策略核心量化体检卡片：
- **总收益率 & 年化复合收益率**
- **夏普比率 (Sharpe Ratio) & 卡玛比率 (Calmar Ratio)**
- **最大历史回撤 (Max Drawdown)**
- **交易胜率 (Win Rate) & 盈亏比 (P/L Ratio)**
- **总手续费支出与交易笔数**

### 2. 累计净值与基准对比曲线 (Cumulative Return)
- **动态交互**：支持框选缩放（Box Zoom）、平移（Pan）、悬停十字光标精准读取任意日期的策略净值与基准点位。
- **超额收益曲线**：清晰展示策略相对大盘指数（如沪深 300）的 Alpha 超额收益变化轨迹。

### 3. 水下动态回撤深度图 (Underwater Drawdown)
- 实时描绘策略每日处于历史最高峰值下方的回撤深度（$0\% \sim -100\%$）。
- **前 N 大回撤区间自动高亮**：算法自动识别历史回撤最深、耗时最长的前 5 大区间，明确标注起止日期与修复周期。

### 4. 月度收益率热力图矩阵 (Monthly Returns Heatmap)
- 纵轴为年份，横轴为 1 ~ 12 月份，单元格以红绿渐变（或国际通用蓝绿渐变）呈现每个自然月的策略盈亏。
- 一眼洞悉策略在不同年份、不同季节性周期下的稳健度。

### 5. 逐笔成交流水明细表 (Trades Table)
- 分页展示全部交易的买卖动作、委托价、实际撮合价、滑点成本、佣金与印花税。
