# 项目简介

**QKA（快量化 / Quant Kit for A-shares）** 是一个为 A 股市场量身定制的、简洁易用的量化投研与回测框架。

传统量化回测框架（如 Backtrader、Zipline 等）功能强大但通常概念繁重、API 复杂，且往往缺乏对 A 股市场特有规则（如 **100 股一手**、**前复权与后复权**、**T+1**、**印花税**、**停牌与 ST 标记**）的开箱即用支持。

QKA 的核心设计目标是：**极简的接口、最少的心智负担、深度的 A 股本土化，以及对现代 AI 编程助手（Claude Code、Cursor 等）的天然友好。**

## 核心设计哲学

### 1. 声明式因子预计算
在 QKA 中，所有技术指标（均线、MACD、RSI、布林带等）和衍生因子均在数据阶段批量声明并向量化预先计算完毕。策略运行阶段只需按需取用已计算好的横截面或历史切片，无需在 `on_bar` 循环内部进行低效重复的 rolling 计算。

### 2. 纯粹的面向对象策略
策略只需继承 `qka.Strategy` 并实现一个 `on_bar(self, date)` 核心方法。回测引擎会在运行时自动为策略注入基础设施（虚拟券商 `broker`、仓位计算器 `sizing`、数据访问器 `_data`），使策略类本身保持轻盈清晰。

### 3. A 股规则原生融入
- **一手 100 股整倍数**：所有买入/卖出方法及仓位算法均强制按手（100 股）向下取整，杜绝因碎股下单导致的异常。
- **真实费率模型**：内置买入/卖出佣金（万分之 2.5，最低 5 元起）、卖出印花税（万分之 5）以及滑点（默认千分之一）。
- **停牌与除权除息**：支持前复权（qfq）、后复权（hfq）与不复权（bfq），并提供停牌日前收价自动补齐。

### 4. 严格防范未来函数与因子预热
- 策略在当前 `date` 只能通过 `self.get()` 获取当天的横截面，或通过 `self.history()` 取得过去的滑动窗口，无法越界访问未来数据。
- 引入 `warmup`（因子预热）机制：对于需要长期窗口的历史因子（如 200 日动量、年线均线），框架在回测区间前自动提前读取历史数据预热，回测首日策略即可拿到有效因子，再也不需要在策略开头手写 `if len(...) < N: continue` 的冗余保护。

### 5. 模拟行情支持
内置 `Simulate` 模块，无需等待真实网络行情即可直接合成单边上涨、单边下跌、均值回归或震荡走势的虚拟标的，用于快速验证策略在特定极端行情下的买卖逻辑。

## 框架全貌对比

| 特性 | 传统回测框架 (如 Backtrader) | QKA (快量化) |
|------|------------------------------|--------------|
| **学习曲线** | 陡峭，概念繁杂（Line, Indicator, Broker, Cerebro） | 极平缓，仅 7 个核心公开类 |
| **A 股适配** | 需自行扩展一手100股、印花税、T+1、复权逻辑 | 原生内置，开箱即用 |
| **数据源集成** | 通常需自行准备 CSV 或编写 Data Feed | 内置 tickflow、baostock、通达信三源，全自动缓存 |
| **因子计算** | 逐 bar 推进计算，易出现性能瓶颈 | 声明式向量化预计算，秒级回测 |
| **因子预热** | 策略内部需自行防御 `NaN` 或跳过初始 bar | 原生 `warmup` 参数，首日即有值 |
| **AI 编程友好** | 复杂语法大模型容易编造不存在的 API | 提供标准化 `SKILL.md`，大模型零幻觉生成代码 |
| **回测报告** | 需借助第三方库或基础 Matplotlib | 内置基于 Plotly 的现代交互式 HTML 诊断报告 |

## 核心组件一览

QKA 整个框架仅由 **7 个核心公开类** 组成，简洁明快：

| 核心类 | 模块全限定名 | 职责说明 |
|--------|--------------|----------|
| **Data** | `qka.Data` | 行情数据加载、多源切换、自动落盘缓存与因子预计算 |
| **Simulate** | `qka.Simulate` | 虚拟标的描述符，用于合成自定义走势验证策略逻辑 |
| **Strategy** | `qka.Strategy` | 策略基类，用户实现 `on_bar` 编写具体的买卖决策 |
| **Broker** | `qka.Broker` | 虚拟券商，执行买卖撮合、扣减费率与管理持仓/现金 |
| **SizingAccessor** | `qka.SizingAccessor` | 仓位计算工具，提供资金比例、固定金额、ATR 等 4 种算法 |
| **Backtest** | `qka.Backtest` | 回测引擎，负责数据驱动推进、撮合路由与绩效计算 |
| **Analysis** | `qka.Analysis` | 常用分析工具，提供 Zigzag 趋势分段、α/β、夏普比率计算等 |
